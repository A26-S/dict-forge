# 🔐 Dictionary Forge

**高效的本地密码字典生成工具** | 为安全审计量身定制

一个功能强大的桌面应用，用于生成符合中国人习惯的详细密码字典，支持高度自由的组合规则和多样化的变形策略。

## ✨ 核心特性

### 🌱 种子数据
- **姓名生成** - 常见中文姓名库 + 昵称 + 网络用语
- **吉祥数字** - 8/6/66/88/888/6666 等寓意数字
- **地名数据** - 省市区、热门城市、地标
- **时间数据** - 年份、日期（4位/6位/8位格式）
- **企业信息** - 品牌名称、公司名、产品名
- **行为习惯** - 常用网站、宠物名称、爱好

### ⚙️ 组合规则引擎
- **拖拽式规则编辑** - 可视化组合规则链
- **笛卡尔积生成** - 支持模块排列组合
- **三套预设方案**
  - 🎯 社会工程学预设（个人信息组合）
  - ⌨️ 键盘轨迹预设（qwerty、1q2w3e4r等）
  - 🎰 吉利数字预设（8/66/888等组合）
- **动态权重** - 高频组合优先生成
- **智能采样** - 大规模生成时自动抽样

### 📦 内置字典库
- **键盘轨迹** - qwerty、1q2w3e4r、asdfgh等
- **常见弱口令** - password、admin、123456等
- **自定义导入** - 支持导入外部词库

### 🔧 高级变形过滤
- **大小写变形** - 首字母大写、全大写、全小写、混合
- **数字替换** - 0→O/零、1→I/L、5→S等
- **谐音替换** - 爱→1314、好运→88等
- **Leet变形** - a→@、e→3等
- **字符串反转** - 正向/反向组合
- **多音字处理** - 同字多音支持
- **繁简转换** - 简体↔繁体
- **拼音首字母** - 中文→拼音简写
- **键盘相邻替换** - typo类密码
- **长度/字符约束** - 灵活的过滤条件

### 🚀 生成与导出
- **实时统计** - 总条目/去重数/过滤数
- **性能优化**
  - 多线程并行生成
  - 布隆过滤器快速去重
  - 流式处理，无需加载全部到内存
- **进度跟踪** - 实时进度条和预估时间
- **多格式导出**
  - `.txt` - 每行一条
  - `.csv` - 带元数据
  - `.json` - 结构化格式
- **采样预览** - 生成前预览样本
- **复制功能** - 快速复制到剪贴板

### 📊 分析与对标
- **熵值评分** - 密码复杂度评估
- **字符分布** - 可视化统计
- **泄露对标** - 与已知弱密码库对比
- **规则贡献度** - 分析每层规则的影响

## 🛠️ 技术栈

**后端引擎**
- **Go** - 核心生成引擎（高性能并发）
- **Python** - 数据处理和规则管理

**桌面前端**
- **Electron** - 跨平台桌面应用框架
- **Vue 3** - UI框架
- **Element Plus** - UI组件库
- **Echarts** - 数据可视化

**数据处理**
- **Bloom Filter** - 高效去重
- **LevelDB** - 本地数据存储
- **SQLite** - 历史记录和配置

## 🚀 快速开始

### 前置要求
- Go 1.21+
- Node.js 18+
- npm/yarn

### 安装与运行

```bash
# 克隆仓库
git clone https://github.com/A26-S/dict-forge.git
cd dict-forge

# 后端编译
cd backend
go build -o dict-forge-server ./cmd/server

# 前端安装
cd ../frontend
npm install
npm run dev

# 打包为桌面应用
npm run electron
```

## 📖 使用示例

### 场景1：生成企业员工常见弱密码
```
种子数据：公司名 + 员工姓名 + 年份
组合规则：笛卡尔积（公司名 + 姓名 + 年份）
变形：首字母大写、数字替换、Leet变形
长度过滤：8-12位
导出：dict-company-2024.txt
```

### 场景2：个人信息相关密码审计
```
种子数据：名字 + 生日 + 手机尾号 + 城市
预设：社会工程学预设
组合：自动关联组合
导出：CSV格式，带元数据
```

### 场景3：键盘轨迹密码生成
```
种子数据：qwerty、1q2w3e4r等
预设：键盘轨迹预设
变形：Leet、大小写
统计：分析熵值分布
```
