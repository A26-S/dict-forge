# 用户指南

## 快速开始

### 第一步：启动应用

1. 在桌面应用主界面，你会看到4个主要功能模块
2. 默认进入"字典生成"页面

### 第二步：选择种子数据

**种子数据**是生成密码字典的基础，包括:

- **姓名** - 输入常见姓名或昵称（逗号分隔）
- **地名** - 输入城市、地标、省份等
- **年份** - 输入年份或日期（支持YYYY、YYYYMM、YYYYMMDD格式）
- **吉祥数字** - 预设8、6等吉祥数字，可自定义

**示例**
```
姓名：张三,李四,王五
地名：北京,上海,深圳
年份：2020,2021,2022
吉祥数字：8,6,88,168
```

### 第三步：选择变形规则

变形规则决定生成的密码有多少种变体。支持以下变形:

| 变形类型 | 说明 | 示例 |
|---------|------|------|
| 首字母大写 | 仅首字母大写 | password → Password |
| 全大写 | 整个字符串大写 | password → PASSWORD |
| 全小写 | 整个字符串小写 | PASSWORD → password |
| Leet变形 | a→@, e→3等 | password → p@ssw0rd |
| 字符反转 | 反向排列 | password → drowssap |
| 数字替换 | 0→O, 1→I等 | password1 → passwordl |
| 混合大小写 | 多种大小写组合 | password → PaSsWoRd |
| 谐音替换 | 爱→1314等 | 爱 → 1314 |

**建议组合**
- **保守方案**：只启用"首字母大写"
- **标准方案**：启用"首字母大写"+"全大写"+"数字替换"
- **激进方案**：启用所有变形选项

### 第四步：设置过滤条件

过滤条件限制生成结果的格式要求:

- **最小长度** - 密码最少位数（建议6-8位）
- **最大长度** - 密码最多位数（建议16-32位）
- **必含数字** - 勾选则所有密码都必须包含0-9
- **必含大写** - 勾选则所有密码都必须包含A-Z
- **必含特殊字符** - 勾选则所有密码都必须包含!@#$等

**示例配置**
```
最小长度：8
最大长度：16
必含数字：☑
必含大写：☐
必含特殊字符：☐
```

### 第五步：点击"开始生成"

1. 系统会显示实时进度条
2. 显示预估完成时间
3. 实时展示样本数据预览

**统计信息**
- **总条目数** - 生成前的理论数量
- **去重后** - 去除重复后的数量（布隆过滤器）
- **通过过滤** - 满足条件的最终数量
- **生成耗时** - 整个过程耗时（毫秒）

### 第六步：导出结果

支持多种导出格式:

**TXT格式**
```
password1
password2
password3
```

**CSV格式**
```
password,entropy,strength,length
password1,42.5,中,9
password2,58.3,强,9
```

**JSON格式**
```json
[
  {"password": "password1", "entropy": 42.5, "strength": "中"},
  {"password": "password2", "entropy": 58.3, "strength": "强"}
]
```

**导出选项**
- 全部导出
- 采样导出（每N条导出1条）
- 按强度导出（弱/中/强）

## 预设方案

### 🎯 社会工程学预设

**适用场景**：针对特定个人或公司的密码审计

**特点**：
- 自动关联个人信息（名字+生日+城市）
- 优先生成高概率密码
- 包含昵称和网络用语

**使用步骤**
1. 切换到"预设方案"页面
2. 点击"社会工程学"卡片
3. 输入目标人物信息
4. 返回"字典生成"点击"应用预设"

### ⌨️ 键盘轨迹预设

**适用场景**：找出typo导致的弱密码

**特点**：
- 包含qwerty、1q2w3e4r等键盘轨迹
- 邻近按键替换
- 手指滑动路径

**预设词库**
```
qwerty / asdfgh / zxcvbnm
1q2w3e4r / 2w3e4r5t
qazwsx / qwe / asd / zxc
```

### 🎰 吉利数字预设

**适用场景**：针对中国用户的密码预测

**特点**：
- 包含8、6、9等吉祥数字
- 支持倍数组合（66、666、6666）
- 包含特殊含义数字（1314=一生一世、520=我爱你）

**常见数字含义**
```
8 = 发财
6 = 顺利
9 = 长久
168 = 一路发
518 = 我要发
1314 = 一生一世
520 = 我爱你
```

## 分析与统计

### 📊 密码强度分析

切换到"分析统计"页面，可以查看:

**分布图表**
- 长度分布 - 生成密码长度的分布情况

- 熵值分布 - 密码复杂度的分布

**对标分析**
- 与已知弱密码库的匹配率

```

名字+地名组合：28%
名字+吉祥数字：20%
Leet变形：12%
大小写变形：5%
```

## 高级用法

### 自定义规则编辑

点击"规则配置"页面，可以:

1. **创建新规则**
   - 选择规则类型（组合/变形/过滤）
   - 配置规则参数
   - 设置权重

2. **拖拽排序**
   - 调整规则执行顺序
   - 更改规则权重

3. **保存为模板**
   - 保存自定义配置
   - 下次快速加载

### 批量导入字典

1. 点击"种子数据"中的"导入"
2. 选择TXT或CSV文件
3. 系统自动识别数据类型
4. 合并到现有种子数据

### 对比分析

1. 生成第一个字典（保存结果）
2. 修改参数生成第二个字典
3. 点击"对比分析"
4. 查看两个字典的差异和重叠

## 常见问题

**Q: 生成的密码数太多，怎么办？**
A: 
1. 增加过滤条件（如增加最小长度）
2. 启用采样导出（每N条取1条）
3. 减少变形规则的数量

**Q: 生成速度很慢？**
A:
1. 检查电脑配置（至少4核CPU）
2. 关闭其他程序释放内存
3. 减少种子数据数量
4. 禁用"混合大小写"（指数级增长）

**Q: 怎样验证生成的字典质量？**
A:
1. 查看熵值分布（平均值>40为好）
2. 检查与弱密码库的重叠率
3. 手动抽查几个样本是否合理

**Q: 可以集成到我的安全工具中吗？**
A: 可以！支持以下方式：
1. 使用REST API调用
2. 导出后通过管道传递
3. 使用内嵌库（Python/Go）

## 安全提示

⚠️ **注意**
- 生成的字典文件包含大量密码尝试，请妥善保管
- 仅用于授权的安全审计，不得用于非法用途
- 建议将字典文件放在加密分区
- 使用完毕后及时删除
- 定期更新种子数据库
